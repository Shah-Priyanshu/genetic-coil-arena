# Data Directory

This directory contains application data:

- `experiments/` - Experiment results and configurations
- `models/` - Trained ML models and neural networks
- `cache/` - Temporary cache files
- `exports/` - Exported experiment data and reports

## Structure
```
data/
├── experiments/     # Experiment data
├── models/         # AI/ML models
├── cache/          # Temporary files
└── exports/        # Export files
```
